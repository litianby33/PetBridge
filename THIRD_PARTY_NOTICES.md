## Installed tools

The app may launch the recipient's installed Codex CLI and unmodified desktop app-tools MCP server. Neither OpenAI executables, plugin servers, Node runtimes, credentials nor conversation records are bundled. Desktop bridging is a compatibility adapter, not a promise of a stable public external API. Python and Pillow are optional local import tools and are not bundled. Their own licenses apply if installed.

OpenAI, ChatGPT and Codex are referenced for interoperability. PetBridge is an independent project, not an official OpenAI product.
