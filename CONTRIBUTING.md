# Contributing

Build with `Build.cmd`, run `scripts/Test.ps1`, and describe the concrete behavior changed plus what was verified. Keep character binding data separate from task adapters. Preserve animation fallbacks, profile isolation, and source-specific quota semantics.

Use synthetic conversation IDs in fixtures. Do not submit login files, private transcripts, app-tools binaries, generated runtime data or artwork without clear redistribution rights. Optional external artwork keeps its own license. Update action `purpose` notes whenever adding or changing a binding.

Run the allowlist packager and archive scanner before attaching a release. Changes affecting a desktop-version-specific adapter should identify the tested version and unsupported paths rather than claiming universal compatibility.
