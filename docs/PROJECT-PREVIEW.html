开始使用

  1. 在仓库 Releases 下载 PetBridge-v1.3.1-windows-x64.zip，完整解压。
  2. 打开其中的 PetBridge 文件夹，双击 Start.cmd，先看默认角色。
  3. 右键人物 → 详细设置 → 绑定角色，按 本机适配指南 绑定自己的环境。
  4. 想换形象，准备自己的 PNG / WebP 图集或静态 PNG，再阅读 角色定制。

源码包用于修改代码，双击 Build.cmd 可以编译。GitHub 自动生成的 Source code ZIP 通常没有 EXE，需要先编译。仅浏览动作、渲染和离线测试不会调用模型。

交给自己的 ChatGPT / Codex

在能访问本机项目文件并执行命令的环境中，打开完整解压的文件夹，发送：

请先阅读 AGENTS.md、README.md 和 docs/CODEX-ADAPT.zh-CN.md。
帮我在这台 Windows 电脑上编译、适配 PetBridge，绑定我自己的本机 Codex。
使用真实本机对话编号，不沿用演示编号；保留已有桌宠、登录配置和项目。
先用默认角色，离线检查动画、气泡和动作回退，再检查本机状态、提问提醒和额度。
不要为验证向聊天发送消息；说明哪些联动通过、哪些受当前应用版本限制。

如果当前聊天只能阅读文件，先让它解释适配步骤，再交给本机 Codex 执行。完整适配提示词

也可以请 Codex 帮你改配色、服装细节或生成动作。用 角色改造提示词，先确认设计和绘图范围，保留原图，再接入角色。

分别控制聊天联动

在「设置 → 联动设置」分别控制普通 ChatGPT 聊天、Work / 云端 Codex 和提问提醒。普通聊天联动默认关闭，不参与思考、三点状态和完成气泡；Work 与本地 Codex 的完成提醒保留。提问提醒独立开启时，桥接仍只读检查等待回复状态。普通聊天完成气泡还需在「提醒设置」中单独开启，单开完成提醒不会绕过已关闭的联动。关闭后重新开启不会补弹已处理的旧完成消息。
