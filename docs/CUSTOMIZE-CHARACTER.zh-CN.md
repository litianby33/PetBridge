# 换角色，也可以请 Codex 帮你改形象

先确定素材来源和改动范围，保留原图，试用满意后再设为默认。

## 已有角色素材

把素材和完整解压的 PetBridge 文件夹交给本机 Codex，发送：

```text
请阅读 AGENTS.md 和 docs/ANIMATIONS.zh-CN.md。
把我的素材接入 PetBridge，先不要改画。查看实际图集，为每个动作填写
purpose、row、column、frameCount、fps 和 fallback，不凭文件名猜位置。
缺少动作就回退；没有跳跃时模拟整体上移后落下。
素材放本机私有角色目录，不加入公共仓库，不覆盖原图和现有角色。
先验证配置并离线预览，让我看过再保存为默认。
素材位置：我附上的文件或另外给你的本机路径。
```

支持透明静态 PNG、PNG / WebP 图集和 `pet.json` 文件夹。常见 8×9、8×11 图集可导入；自定义网格需要实际查看和配置。

## 让 Codex 帮你改人物形象

可以换配色、调整服装、修手、改发饰，也可以先设计一个新角色。修改图片需当前环境有可用的图像编辑／生成工具。没有工具时，先完成软件适配并说明素材需求。

复制这段，把方括号换成自己的想法：

```text
我想改 PetBridge 的人物形象。先阅读项目的角色和动画说明，查看参考图。
希望改成：[例如：灰蓝配色、短发、简洁外套、小狐狸耳朵]。
希望保留：[例如：原角色比例、像素密度、轮廓和表情]。

先只给一张透明背景的正面站立设计图，让我确认，不生成整套动作。
优先用当前已有的图像工具，不自行改用收费 API，不索要密钥。
先说明预计生成几张图，控制消耗，不重复画已经满意的部分。
保留原始素材，把新版本放私有目录；不公开私人角色或照搬来源不明素材。

确认外观后，再做必要的待机、左右走路、招手、跳跃和思考。
走路必须左右脚交替，逐帧核对，不能把同一个姿势抖动当成走路。
统一人物大小和脚底位置，待机低帧率；可选缺失动作复用基础动作。
每段写清用途、位置、帧数、fps 和备用动作。
给我静态帧对照及可播放预览，检查空白帧、越界、抖动，再接入项目。
不要改动我电脑上的其他桌宠。
```

这段提示词本身不会开始绘图；你交给自己的助手并确认设计后才继续。换成现成图不需要重新生成。

## 一张图也能先用

| 已有素材 | 可以先得到什么 |
| --- | --- |
| 单张站立图 | 站立、拖动、气泡、额度、贴边半身；跳跃模拟 |
| 待机 + 思考 | 任务进行时切换思考，结束后回待机 |
| 左右走路 | 拖动／跑向边缘时播放 |
| 招手 + 原生跳跃 | 空闲招手、通知时播放自己的跳跃 |
| 16 向注视 | 桌宠输入框看向光标、合适的贴边探头图 |

失败、等待、收尾是可选动作，没有就写 `frameCount: 0` 和备用动作，不用空白格冒充。

临时试用：`PetBridge.exe --character "角色目录\character.json" --offline`。满意后：右键 → 详细设置 → 绑定角色 → 选择自己的 `character.json`，下次启动生效。绑定编号和私人素材都不需要发给作者。
