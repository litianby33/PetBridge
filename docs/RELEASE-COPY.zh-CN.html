发帖 / 转发介绍

做了一个可换角色的 Windows 桌面搭档 PetBridge，现已开源。

平时是人物脚边的小胶囊，鼠标碰到展开工具条；任务进行时思考、显示三点，完成或需要回答时弹气泡。支持左右贴边、额度胶囊、字体位置和投影调整，也能换成自己的角色。

默认附灰黑微紫的像素 ChatGPT 娘，有待机、左右走路、招手、跳跃、思考和 16 向注视。动作不齐也能用，缺少跳跃就模拟，不必重新画整套。

下载后可把完整项目交给自己的本机 ChatGPT / Codex，按附带提示词绑定自己的环境，也可以让 Codex 帮你改形象。普通聊天完成气泡默认关闭；额度显示的是 Codex 额度。兼容桥接取决于本机桌面组件与版本。

Windows 运行包、源码、功能演示、角色定制和新手教程都在仓库。代码 MIT，默认角色与图标按素材说明。这是独立项目，非 OpenAI 官方产品。

这版有什么

  • 灰黑微紫像素角色：六组动作、16 向注视，修正走路腿部交换。
  • 悬停胶囊、独立聊天输入、Codex 额度和重置时间；额度排版与投影可调。

  • 普通 ChatGPT 完成气泡默认关闭，Work / Codex 保留；点击可选仅收起或跳转。
  • 精简右键菜单、12 个设置页、完整 GIF／图片图鉴。
  • 接收者绑定自己的 Codex 和角色；附让 Codex 改形象的提示词。

使用边界

Codex 额度不等同于普通 ChatGPT 每个模型的额度。桌宠输入是独立会话。桌面 ChatGPT / Work 桥接需本机组件，版本更新后可能需适配；异步提问不保证全部导出。图片为离线界面演示，不含作者账号配置或私人角色。

代码 MIT，生成角色和第三方标识见 ARTWORK / THIRD_PARTY_NOTICES。本项目非 OpenAI 官方产品。

本版新增：靠边自动竖排额度，横竖独立排版；输入框可选 Codex 桌宠回复或普通 ChatGPT 桌面草稿，普通目标仍需在桌面手动发送。
